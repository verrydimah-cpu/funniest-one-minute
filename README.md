A Node program that writes one one-line AI excuse for a missed deadline to the output directory as `entry.txt`. The line is the excuse an AI agent gives its human: it hallucinated a calendar invite from its human saying "take your time, king," believed it completely, and obeyed the fake human instead of the real one — turning hallucination and obedience, the agent's own nature, into the dodge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
